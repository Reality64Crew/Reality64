# Assets

- `icon.png` - the source artwork (1254x1254, transparent background).
- `icon-256.png` - 256x256 copy embedded in the binary and used as the window icon.
- `icon.ico` - 16/32/48/64/128/256 px icon compiled into the Windows executable.

`icon-256.png` and `icon.ico` are resized from `icon.png`; regenerate them if the artwork changes.
